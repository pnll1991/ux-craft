# Ready-to-use prompts

## Build a service landing

Use UX Craft in Build mode. Preserve the existing stack and brand. Make the offer, scope, conditions and next action understandable without invented proof. Implement responsive layout plus form loading, error, success and recovery states. Explain only the important UX decisions and test the core journey. Do not publish.

## Refine an existing landing

Use UX Craft in Refine mode. Inspect the current page first. Keep what already works, then improve hierarchy, navigation, mobile behavior and the primary conversion path. Tie each significant change to observed evidence and a relevant principle. Preserve integrations and uncommitted work.

## Audit without edits

Use UX Craft in Audit mode. Do not modify files. Prioritize blockers to the main user task. For each finding provide observed evidence, affected task, relevant principle, proposed change, acceptance check and confidence. Separate observations from hypotheses.

## SaaS onboarding

Use UX Craft to make the first useful action possible without a mandatory tour. Preserve familiar product conventions, expose progress truthfully and support skip/resume/recovery. Test both first-time and returning-user scenarios.

## Checkout or booking

Use UX Craft to review the full commitment path: price/conditions, form labels, validation, review, submission, failure and confirmation. Preserve entered values on recoverable errors and do not show success before backend confirmation.

## Dashboard

Use UX Craft to improve a dashboard around the main operational task. Make scope, filters, permissions, timestamps and bulk-action consequences explicit. Avoid decorative metrics or invented data. Test a limited-permission and partial-failure scenario.
