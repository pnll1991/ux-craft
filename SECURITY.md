# Security and privacy

The installed skill is instruction-only. The repository’s installer and validators run locally; the publisher contacts GitHub only after explicit `--execute`. The demo makes no network requests and stores no form data.

Review downloaded code and instructions before use. Do not include secrets, customer data or private screenshots in issues or examples. The release manifest limits files but is not a substitute for reviewing their contents.

For a vulnerability report, provide a sanitized description and minimal reproduction without credentials. Use GitHub’s private reporting feature only if the maintainer has enabled it; otherwise request an appropriate private channel without posting sensitive details publicly. Do not test against third-party systems.

Dependencies used by an agent client or an optional browser test are outside this package’s instruction-only runtime. Keep your tools updated according to their maintainers’ guidance.
